# Instagram Login UI (Demo)

این پروژه فقط **رابط کاربری (UI)** صفحه‌ی لاگین اینستاگرام را به‌صورت کلون بصری (HTML/CSS) پیاده‌سازی می‌کند.

## نکته‌ی مهم
- این فرم **هیچ منطق بک‌اندی ندارد** — چیزی ارسال، اعتبارسنجی یا در دیتابیس ذخیره نمی‌شود.
- دکمه‌ی "Log in" صرفاً جلوه‌ی ظاهری (فعال/غیرفعال شدن) دارد و submit واقعی انجام نمی‌دهد.
- هدف این پروژه صرفاً نمایش طراحی (UI) است، نه جمع‌آوری اطلاعات کاربران.

## اجرا
```bash
php -S localhost:8000
```
سپس به آدرس `http://localhost:8000` بروید.
